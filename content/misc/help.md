# Help

*AJB-OS v1.0.0 — Command Reference*

---

## Navigation

| Command | Description |
|---|---|
| `dir` | List files in the current directory |
| `cd <dir>` | Enter a directory (e.g. `cd about`) |
| `cd ..` | Go back to parent directory |
| `type <file>` | Display a file's contents (e.g. `type bio.txt`) |
| `pwd` | Show current path |
| `cls` | Clear the screen |

---

## Shortcuts

| Command | What it does |
|---|---|
| `whoami` | Short intro — start here |
| `about` | Navigate to the ABOUT directory |
| `work` / `cv` | Show full career timeline |
| `skills` | Navigate to the SKILLS directory |
| `contact` / `hire` | Show contact links |
| `projects` | Navigate to the PROJECTS directory |

---

## Search & Utilities

| Command | Description |
|---|---|
| `find <keyword>` | Search all content (e.g. `find cms`, `find "internal tools"`) |
| `append <file> [file2...]` | Display multiple files combined (e.g. `append about/bio.txt skills/core-skills.txt`) |
| `echo <text>` | Print text to the terminal |
| `date` | Show the current date |
| `time` | Show the current time |

---

## System

| Command | Description |
|---|---|
| `mode dark\|light` | Switch visual theme (e.g. `mode light`) |
| `country [code]` | Language/region settings (localization WIP) |
| `history` | Show command history |
| `crt on\|off` | Toggle CRT scanline effect |
| `help` | Show this screen |
| `exit` | Try it |

---

*Tip: Use ↑ / ↓ arrow keys to cycle through previous commands.*  
*Tip: Press Tab to autocomplete filenames in the current directory.*  
*Tip: Some commands are hidden. Explore.*
