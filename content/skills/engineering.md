## Approach

Engineering for content platforms requires a different kind of precision than general application development. Content has edge cases that product specs rarely anticipate. I write software that handles that variance gracefully.

I lean toward readable, maintainable code over clever abstractions. I care about the systems around the code as much as the code itself: the deployment pipeline, the content model, the editorial workflow.
