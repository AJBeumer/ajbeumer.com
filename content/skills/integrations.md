# Integrations

---

## Integration experience

Building reliable connections between systems is a significant part of platform engineering. My integration work spans:

**API integrations**  
RESTful API consumption and design, webhook handling, authentication patterns (OAuth, API keys, JWT).

**Content platform integrations**  
Connecting CMS platforms to external systems: DAM systems, search platforms, delivery APIs, analytics tools.

**Data pipeline work**  
Moving and transforming content data between systems, with attention to consistency, idempotency, and failure recovery.

**System-of-record patterns**  
Understanding which system owns which data, and designing integrations that respect those boundaries rather than creating messy bidirectional sync problems.

---

## What I've learned

Integrations fail in boring ways — network timeouts, schema drift, undocumented API quirks, rate limits. Building resilient integrations means anticipating failure modes, not hoping they won't occur.

Documentation and observability are part of the integration, not extras added at the end.
